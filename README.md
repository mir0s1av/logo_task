## Description

Logo uploading application.

## Installation

```bash
$ yarn install
```

## Running the app

```bash
# watch mode
$ yarn run start:dev

```

Make sure you have created `.env` file in the root derictory with the following variables:

```
AWS_S3_REGION
AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY
AWS_S3_BUCKET_NAME
DATABASE_URL
```

Please aslo note this application is set to store data in a mongodb database.
